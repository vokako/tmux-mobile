# Internationalization (i18n)

## Description
Lightweight client-side i18n with no external dependencies. Supports English and Chinese.

## Scope of Impact
All Svelte components with user-facing text: every page/component with user-facing text (App, Settings, Preferences, Sessions, Terminal, Files, Team, and the shared ui/ pieces).

## Behavior Details
1. On first visit, locale auto-detected from `navigator.language` (starts with `zh` → Chinese, else English)
2. User can switch language in Settings panel (Language pill buttons: EN / 中文)
3. Locale persisted to `localStorage` key `tmux_locale`
4. All UI strings retrieved via `t('key')` function from `src/lib/core/i18n.svelte.ts`
5. Language change takes effect immediately (components re-read `t()` on next render)

## Implementation
- `src/lib/core/i18n.svelte.ts` — single module exporting `t()`, `setLocale()`, and the reactive `i18n` state (`i18n.lang`)
- Translation keys are flat strings (no nesting)
- Fallback chain: current locale → English → raw key
- `i18n.lang` is Svelte 5 `$state`; components using `t()` re-render on change automatically

## Constraints
- Only EN and ZH supported currently
- Technical terms (tmux, WebSocket, Git subcommands) are not translated
- ANSI terminal output and CLI agent messages are not translated (they come from external tools)
